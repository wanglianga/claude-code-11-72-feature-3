# 排口污染负荷离线复核台

澄川水务集团某污水厂排口的 **COD、氨氮、流量** 记录离线复核工具。断网环境可完整运行：
接入账与文件指纹、点位/设备实例、校准系数与状态有效期、片段编织与来源链、
自然日/月污染负荷与不确定范围、覆盖率与申报资格、迟到读数的锁定窗口复算候选。

在负荷复核之上，本台把“连续监测超标”作为**事件**处理：标准适用库、事件推导器、
间隔证据评估器、处置关联簿、申报核对页。事件不是“某一行读数大于阈值”，而是由
有效浓度片段 × 标准窗口 × 状态边界 × 间隔证据共同推出的时间区间；限值中途调整必切开事件，
清洗开始即终止插值链，采样空档不得凭相邻高值臆造持续超标。

技术栈：**React 19 + TypeScript 5.9 + IndexedDB(idb) + WebWorker + Vite 7**。
所有重计算在 Worker 内完成，主线程只读写本地库与渲染；数据不出本机。

## 5. 事件监控口径（与事件引擎逐条对应）

### 5.1 事件如何被推出

| 要素 | 规则 |
| --- | --- |
| 有效浓度片段 | 同一仪表实例、同一校准体制、OK 状态、标称间隔内的分段线性浓度；与负荷计算共用同一编织结果 |
| 标准窗口 | 按标准库规则生效边界切分，窗口内限值唯一；跨越窗口的事件必须切开 |
| 状态边界 | 清洗/校准/旁路/故障一开始立即终止插值链，事件只能以“开放”结束 |
| 间隔证据 | 相邻实测读数之间线性插值求穿越点；只在同一实例/校准体制/OK 状态内插值 |
| 采样空档 | 两侧均实测超限且空档 ≤15 分钟时并入同一事件，记为 `GAP_UNKNOWN`，不计入超标时长 |
| 边界读数 | 边界读数恰等于限值只能证明“到达限值”，判 `OPEN_BOUNDARY`，不得推定已结束 |

证据段类型只有四种：`MEASURED`（两端实测均超限）、`INTERPOLATED`（一端超限一端不超限）、
`GAP_UNKNOWN`（空档）、`UNMODELLED`（未建模）。事件状态：
`CLOSED / OPEN_BOUNDARY / OPEN_END_OF_WINDOW / OPEN_DATA_GAP / OPEN_LIMIT_CHANGE`。

### 5.2 两种派生方案（同一套规则，同一冻结输入必须同结论）

| | 读数到达即物化（PERSIST_SNAPSHOT） | 查询时推导（DERIVE_ON_DEMAND） |
| --- | --- | --- |
| 持久化 | 带来源索引的事件片段 + 输入签名 | 原始有效片段与法规条件 |
| 优势 | 报表响应快 | 补传/限值调整影响小 |
| 代价 | 补传或限值调整使来源窗口内派生片段成批失效 | 计算压力移到查询、调查与月末 |
| 失效判定 | 输入签名（读数/状态/校准/标准）变化即判过旧 | 每次现算，无过旧问题 |
| 适用 | 查询负载高、补传密度低 | 补传/限值调整频繁、查询量中等 |

- 旧快照**不得**替代当前证据：`resolveDayEvents` 在快照过旧且不允许刷新时返回空结果并给出阻断说明；
  “派生影响”页显式刷新，并逐项列出新增/删除/变更事件。
- 一致性校验入口：「事件时间线」「派生影响」页的“双方案一致性校验”，
  或 `tests/events.test.ts` 的“两种派生方案一致性”。

### 5.3 申报核对

- 自然日申报值 = 各事件实测时长 + 可插值时长；未知空档单列、不计入上报值。
- 草稿冻结事件集合与输入签名；补传读数或限值调整 → 草稿自动 `NEEDS_RECHECK` 并逐项列出变化。
  转入复核的草稿不会因“再次核对无差异”自动恢复，需复核人填写附注并显式恢复后再核对出具。
- 迟到处置记录只能补证（写进关联簿与说明），不能删除事件或宣布超标已消失。

## 6. 计算口径（与引擎一致）

- 时间轴：`alignedAt = sampledAt + clockOffsetMs`，自然日按 Asia/Shanghai（UTC+8）。
- 片段边界：自然日端点、仪表实例/绑定交接、校准生效、状态切换、采样空档端点。
- 状态：仅 `OK` 可积分；`FLUSH/CALIB/BYPASS/FAULT` 整段排除并保留状态 ID。
- 采样空档：同一实例相邻有效读数间隔 > `nominal × 2.5`；空档自「上一读数 + 一个标称间隔」
  起算。段端最多保持一个标称间隔，不跨校准系数插值。
- 负荷：`∫ c(t)·q(t) dt / 3.6e6`（mg/L × m³/h × 秒 → kg）。
- 不确定范围：逐片段相对不确定度平方和开方 × `k`（默认 2）；重采样路线额外叠加
  梯形法解析误差界 `|c′q′|h³/6`。
- 覆盖/资格：覆盖率 = 有效积分秒 / 86,400；低于申报线 15pp 以上判不可申报。

### 两条积分路线

| | 逐有效片段积分（默认） | 经误差界验证的重采样积分 |
| --- | --- | --- |
| 局部证据 | 每个片段保留读数/校准/状态/文件 | 保留边界，片段内网格化 |
| 窄事件 | 40 s 冲击边界精确到读数时刻 | 需斜率上界 + 细分，否则会漏检 |
| 汇总成本 | 片段与结点多，查询较重 | 网格单元轻，便于跨层聚合 |
| 证明责任 | 无需额外证明 | 必须证明负荷范围、峰值、阈值穿越不变 |

核验阈值（`src/domain/engine.ts`）：负荷相对偏差 ≤0.5%，1h 峰值窗口中心偏移
≤ max(30 s, 1 网格)，阈值穿越并集对称差 ≤2 s，网格细分后无未决单元。

## 7. 申报与迟到复算

1. 「覆盖与资格」出具申报 → 生成 `FILED` 版本；截止接收时刻默认取该点位当日数据集的
   最大 `receivedAt`（样例为 2026-11-19 07:20），并锁定来源窗口、
   来源读数 ID 快照与来源文件指纹。
2. 「复算候选」导入迟到补录 → 读取落在锁定窗口内且 `receivedAt > 截止` 的读数。
3. 生成候选：只把迟到读数并入重算，原申报版本**不做任何修改**（`declarationOverwritten: false`），
   候选保存 `baseline` / `recomputed` / `diff` 与受影响片段。
4. 人工填写复核附注并标记 `REVIEWED`；是否作为下一版申报依据由人工决定。

## 9. 已知边界

- 样例覆盖 2026-11-18 单日；月度页会明确显示「有数据 1 天 / 缺 29 天」，不补零。
- 时钟校正量来自设备台账的固定值；时钟漂移本身未建模，但偏移不确定度计入区间说明。
- 流量与浓度读数均取自一个排口的同一时刻对齐序列；跨厂站对比仅做展示，不合并负荷。
- 事件页的“全天/聚焦”视图与表格由服务端渲染冒烟测试覆盖；真实浏览器中的点击交互
  （点事件条、切策略、刷新快照）未在本容器内人工点验。
- 本工具不替代法定监测数据有效性判定，只提供可追溯的复核证据与缺口量化。
